# 📊 Superstore Sales Dashboard in Excel

Welcome to my **Superstore Dashboard**, created using Microsoft Excel as part of my Advanced Excel learning journey.  
This dashboard is based on the popular *Superstore Dataset*, widely used in data analysis and visualization practice.

--->>

## 🚀 Project Overview

The objective of this project was to analyze sales performance across different regions, categories, and segments using real-world data.  
This Excel dashboard provides a visual summary of sales, profit, quantity sold, and shipping performance.

### It includes:-

- ✅ **Bar Chart** – for category and sub-category wise comparison.
- ✅ **Pie Chart** – to represent market share by region or segment.
- ✅ **Line Chart** – to show monthly/quarterly sales trends.
- ✅ **Column Chart** – for customer or region-wise sales volume.
- ✅ **Sparklines** – for mini performance trends.
- ✅ **Original Superstore Dataset** – cleaned and formatted for Excel use.
